| * | 04-07-2026 | Analysed |

# Description

Stakeholders keep adding "small" features directly in review meetings, bypassing the change process. Each addition looks harmless, but together they consume the schedule buffer and blur the release criteria.

# Probability

4

# Impact

3

# Response

Reduce: every new feature request becomes a written change request with an estimate before it is discussed; the release scope is frozen at the iteration boundary and changes are traded, not added.

# Monitoring

Count the scope changes accepted per iteration; more than two in a row triggers a re-plan of the release date.

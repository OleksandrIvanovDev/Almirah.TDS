# Description

A company-wide cost review threatened to cut the project budget in the middle of the release, which would have forced the team to shrink before the feature freeze.

# Probability

2

# Impact

3

# Response

Avoid: the release scope was re-cut into a funded core and an optional tail, and the core was signed off by the sponsor as protected. The cost review concluded on 07-07-2026 without touching the project.

# Monitoring

None; the risk is closed. Reopen if a new cost review is announced.

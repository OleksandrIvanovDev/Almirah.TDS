title: "PRJR-003: Estimate-Driven Schedule Overrun"
---

# Status

|  | Date | Status |
|:---:|---|---|
| * | 02-07-2026 | Identified |

# Description

The plan is built from single-point estimates given under pressure. Historical data from the previous two releases shows actual effort running 30 to 50 percent above the estimates, which the current schedule does not absorb.

# Probability

3

# Impact

3

# Response

Reduce: re-estimate the remaining work as focused and safe ranges, plan against the aggregated buffer rather than padding every task, and track buffer consumption weekly.

# Monitoring

Weekly: buffer consumed versus work completed; entering the last third of the buffer before the last third of the work triggers descoping.
